How to read this
  1. Start with No model (baseline) for JS, then for GPU. That's the tab's whole budget right now.
  2. Run each engine with the same model. Budget minus "left after" is roughly what the engine costs.
  3. "died while loading" means the engine's loading peak is too big for this phone, whatever it costs once loaded.
  4. The tab is expected to die at the end of a memory measurement; that's how it finds the limit. Reopen the page each time.
  5. Numbers move with what else the phone is doing. Close other tabs and apps, and repeat a run before trusting a gap under ~100 MB.
